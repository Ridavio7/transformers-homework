## Часть 1. Attention from Scratch

В первом ноутбуке реализованы четыре пропуска:

1. `split_heads` — преобразование `(B, L, d_model)` в `(B, n_heads, L, d_head)` с сохранением соответствия каналов головам.
2. `merge_heads` — обратное преобразование после attention.
3. `scaled_dot_product_attention` — вычисление scaled dot-product attention, применение маски, softmax по оси ключей и dropout.
4. `TransformerBlock.forward` — pre-norm блок с двумя residual connections.

Функция `scaled_dot_product_attention` возвращает два объекта:

- `out` — контекстные представления, полученные взвешенной суммой `Value`;
- `weights` — матрицу весов внимания, которую можно использовать для анализа и визуализации.

Подробный разбор: [`reports/attention_analysis.md`](reports/attention_analysis.md).

**Результат проверок:** 17 из 17 проверок пройдены.

## Часть 2. Bug Hunt

Во втором ноутбуке найдены и исправлены три семантические ошибки:

1. Нумерация позиций в sinusoidal positional encoding начиналась с 1 вместо 0.
2. `LayerNorm` вычислял среднее и дисперсию по оси batch вместо последней оси признаков.
3. `softmax` в scaled dot-product attention применялся по оси Query вместо оси Key.

Подробное объяснение механизма каждой ошибки и исправления: [`reports/bug_analysis.md`](reports/bug_analysis.md).

**Результат проверок после исправлений:** 17 из 17 проверок пройдены.

## Обучение MiniGPT

После исправления ошибок выполнено короткое обучение символьной MiniGPT на искусственном корпусе:

```text
алгоритм внимания смотрит на все позиции сразу.
```

Строка повторяется 200 раз. Это намеренно простой диагностический корпус: эксперимент проверяет, что модель способна оптимизировать next-character prediction и воспроизводить шаблон. Он не является оценкой качества полноценной языковой модели.

| Параметр        |                                        Значение |
| --------------- | ----------------------------------------------: |
| Тип токенизации |                                    Посимвольная |
| Размер словаря  |      Вычисляется из уникальных символов корпуса |
| `context_size`  |                                              64 |
| `d_model`       |                                             128 |
| `n_heads`       |                                               4 |
| `n_layers`      |                                               2 |
| `d_ff`          |                512 (по умолчанию `4 * d_model`) |
| `dropout`       |                                             0.1 |
| Optimizer       |                                           AdamW |
| Learning rate   |                                          0.0003 |
| Batch size      |                                              32 |
| Training steps  |                                             600 |
| Seed обучения   |                                              42 |
| Устройство      | CPU (`torch 2.15.0+cpu` в сохранённом ноутбуке) |

Функция потерь изменилась с **3.1566** на первом шаге до **0.0293** после 600 шагов (seed `42`). График автоматически сохраняется в [`results/loss_curve.png`](results/loss_curve.png).

Пример генерации автоматически сохраняется в [`results/generation.txt`](results/generation.txt). Файл содержит seed, число шагов обучения, начальное и конечное значения loss, а также сгенерированный текст.

## Воспроизводимость

### Проверенное окружение

В метаданных ноутбуков указаны Python **3.12.10** и kernel `python3`. В выводе ячеек установки зафиксирован PyTorch **2.15.0+cpu**. Версии NumPy и Matplotlib в исходных ноутбуках достоверно не зафиксированы, поэтому в `requirements.txt` для них заданы диапазоны, а не выдуманные точные версии.

### Установка

```bash
git clone https://github.com/Ridavio7/transformers-homework.git
cd transformers-homework

python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Запуск

```bash
jupyter lab
```

Откройте ноутбуки в каталоге `notebooks/` и выполните ячейки сверху вниз. В конце каждого ноутбука должен появиться результат `17 из 17`, а во втором ноутбуке — кривая обучения и пример генерации.

### Seed и детерминизм

В Bug Hunt преподаватель указал индивидуальный вариант `seed 42`. В эксперименте обучения используется `SEED = 42`, который устанавливается **до** создания модели, генерации батчей и инициализации оптимизатора. Это обеспечивает воспроизводимость и согласует запуск обучения с указанным вариантом задания.

В `reproducibility.py` вынесена общая настройка seed и детерминированного режима. Для точного сравнения с сохранённым результатом используйте CPU и ту же версию PyTorch. Даже при фиксированном seed идентичность результатов между разными версиями библиотек и аппаратными платформами не гарантируется.
